# SECam

SECam превращает старый iPhone в камеру наблюдения. Это одна веб-страница (`index.html`) без внешних библиотек, которая работает и как камера, и как экран для просмотра. Видео передаётся напрямую между устройствами по WebRTC.

Чтобы устройства нашли друг друга, страница обменивается короткими сообщениями через три публичных MQTT-брокера сразу (HiveMQ, Mosquitto, EMQX): хватит любого одного. Видео через них не идёт. Сообщения зашифрованы AES-GCM ключом, выведенным из кода комнаты, поэтому без кода их нельзя прочитать или подделать. Списки брокеров и STUN-серверов находятся в начале скрипта (`BROKERS`, `ICE_SERVERS`).

`diag.html` проверяет, какие сигнальные и STUN-серверы доступны с устройства. Пригодится, если провайдер начнёт что-то блокировать.

## Запуск

1. Выложите репозиторий на GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**. Нужен HTTPS, иначе Safari не даст доступ к камере.
2. На айфоне откройте страницу, нажмите «Сгенерировать» (или введите свой длинный код) и затем «Это камера».
3. Внизу появится ссылка для просмотра (`…#view=<код>`). Откройте её на любом устройстве. Код находится после `#`, поэтому он не уходит на хостинг.

## Подготовка айфона

- Настройки → Экран и яркость → **Автоблокировка → Никогда**. Держите телефон на зарядке.
- Не сворачивайте Safari: в фоне iOS останавливает камеру. Когда страница снова на экране, захват перезапускается сам.
- Кнопка «Затемнить» закрывает картинку чёрным экраном, но трансляция продолжается.
- Включите **Универсальный доступ → Гид-доступ**, чтобы телефон не вышел из Safari случайно.

## Ретранслятор (TURN): работа через мобильный интернет и строгие сети

Если оба устройства за симметричным NAT (мобильный интернет, гостевой Wi-Fi, корпоративная сеть), прямое соединение невозможно, и видео должно идти через TURN-ретранслятор.

1. Зарегистрируйтесь на [metered.ca](https://www.metered.ca/tools/openrelay/) (бесплатно 20 ГБ в месяц) и создайте приложение.
2. На **камере** откройте стартовый экран → «Ретранслятор (TURN)», впишите адрес приложения (`myapp.metered.live`) и API-ключ.
3. Нажмите «Проверить ретрансляторы»: хотя бы один адрес должен показать ✓.

Настраивать нужно только камеру: зрители получают учётные данные от неё по зашифрованному каналу. Ключ хранится только в `localStorage` айфона и в репозиторий не попадает. Ответ Metered кэшируется, поэтому кратковременная недоступность сервиса не мешает. Можно указать и свой TURN-сервер (например, coturn на VPS).

Ретранслятор используется, только если прямое соединение не удалось. Видео 1,5 Мбит/с через TURN расходует около 0,7 ГБ в час. В строке статуса видно, как идёт видео: «напрямую», «локальная сеть» или «через TURN».

Флажок «Резервный общий Open Relay» включает бесплатный общий сервер Metered без регистрации. Он часто перегружен или недоступен, поэтому полагаться на него не стоит.

## Устойчивость

- При обрыве связи (смена Wi-Fi ↔ LTE, просадка сети) соединение восстанавливается через ICE restart без пересоздания сессии. Если за 45 с восстановить не удалось, подключение начинается заново.
- Потерянные сигнальные сообщения (offer/answer) отправляются повторно.
- Зависшие соединения с MQTT-брокерами обнаруживаются по ping в течение 35 с. При появлении сети или возврате страницы на экран переподключение происходит сразу.
- Если iOS перезагрузит вкладку камеры, трансляция запустится сама. Кнопка «Выход» отключает автозапуск.

## Безопасность

Каждый, кто знает код комнаты, может смотреть видео. Поэтому код должен быть длинным и случайным (кнопка «Сгенерировать»). Одновременно к камере подключаются не больше трёх зрителей.
