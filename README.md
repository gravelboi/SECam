# SECam

SECam превращает старый iPhone в камеру наблюдения. Это одна веб-страница (`index.html`), которая работает и как камера, и как экран для просмотра. Видео передаётся напрямую между устройствами по WebRTC. Сервер PeerJS Cloud нужен только для того, чтобы устройства нашли друг друга: через него не идёт видео.

## Запуск

1. Выложите репозиторий на GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**. Нужен HTTPS, иначе Safari не даст доступ к камере.
2. На айфоне откройте страницу, нажмите «Сгенерировать» (или введите свой длинный код) и затем «Это камера».
3. Внизу появится ссылка для просмотра (`…#view=<код>`). Откройте её на любом устройстве. Код находится после `#`, поэтому он не уходит на хостинг.

## Подготовка айфона

- Настройки → Экран и яркость → **Автоблокировка → Никогда**. Держите телефон на зарядке.
- Не сворачивайте Safari: в фоне iOS останавливает камеру. Когда страница снова на экране, захват перезапускается сам.
- Кнопка «Затемнить» закрывает картинку чёрным экраном, но трансляция продолжается.
- Включите **Универсальный доступ → Гид-доступ**, чтобы телефон не вышел из Safari случайно.

## Если не подключается

Если оба устройства за симметричным NAT (часто так бывает на мобильном интернете), прямое соединение не установится, и страница покажет подсказку. В этом случае добавьте TURN-сервер в массив `ICE_SERVERS` в начале скрипта.

## Безопасность

Каждый, кто знает код комнаты, может смотреть видео. Поэтому код должен быть длинным и случайным. PIN-код на просмотр запланирован.
